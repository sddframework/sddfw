# Governance

SDDFW is a founder-led open source project. Alfonso José García Bañón
([@alfoncode](https://github.com/alfoncode)) is the founder, organization owner,
and primary maintainer.

## Decisions and collaboration

Everyone can propose ideas, report problems, improve documentation, and submit
pull requests. Discuss substantial changes before implementing them so that
contributors and the maintainer can agree on the problem and scope.

The primary maintainer makes final decisions about project direction, merges,
releases, and access to the official repositories. Explain material decisions
in the relevant issue, discussion, or pull request so that others can follow
the reasoning.

## Ownership

The organization hosts the official SDDFW repositories. Repository ownership
and maintenance do not transfer contributors' copyright to the maintainer.
Contributions follow the license and contribution terms published in each
repository.

Additional maintainers can be appointed by the primary maintainer as the
community grows. Their role and scope should be documented publicly; use the
permissions needed for that role.

## Current stage

The framework is in early development. The v0.1 preview provides a local CLI,
coding-agent workflow, Playwright acceptance reports, and a runnable fullstack
example. It is installed from source; there is no npm registry release yet.
The landing's interactive report remains an illustrative sample, separate from
the executable example. Ideas and proposed adapters remain proposals until the
project implements and verifies them.
